# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues. Instead, open a [private security advisory](https://github.com/Bossman556/ruffle3d/security/advisories/new) on GitHub. Describe the problem, how to reproduce it, and what an attacker could do with it.

You'll get a reply as soon as possible. Once the problem is confirmed, we'll work on a fix and credit you when it's released, unless you'd rather stay anonymous.

## What's in scope

- The Ruffle3D app, in the browser and the desktop version (`src/`, `electron/`)
- Opening project, STEP, STL and DXF files (malicious files are a real concern for CAD software)
- The packaging and launcher scripts (`scripts/`)

## Supported versions

Security fixes go into the latest release.
