Install

Windows Your system

  1. Download the .zip and choose Extract all.
  2. Open the folder and double-click Start Ruffle3D (Windows).cmd.
  3. Ruffle3D opens in your default browser. Keep the small console window open while you work.

If Windows SmartScreen appears, choose More info and then Run anyway. The launcher only starts a local web server on your computer.

macOS Your system

  1. Download the .zip. Safari unzips it automatically.
  2. Right-click Start Ruffle3D (macOS).command and choose Open. You only need to do this the first time.
  3. Ruffle3D opens in your default browser.

The macOS launcher needs Node.js or Python 3. If neither is installed, use the browser install below.

Linux Your system

  1. Download and unzip the package.
  2. Run ./start-ruffle3d.sh from the folder.
  3. Ruffle3D opens in your default browser.

Needs Python 3 or Node.js. Most distributions include Python 3.

Or install from your browser

In Chrome or Edge, open Ruffle3D and choose Install Ruffle3D from the address bar or the app's Project menu. You get a desktop window and an app icon. After the first launch it keeps working without an internet connection.
