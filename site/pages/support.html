Common problems

My projects disappeared

Projects are stored by the browser for the address Ruffle3D runs on. If you started it in a different way (a different launcher, browser or port), your projects are still in the original place. Start Ruffle3D the way you did before. To move designs between setups, use Download project file and Open file from disk.

The launcher opens but the page is blank

Ruffle3D needs a recent browser with WebGL 2 and WebAssembly: Chrome or Edge 110+, Firefox 115+, or Safari 16.4+. Update your browser, or set one of these as your default. The status bar at the bottom of the app shows whether the geometry kernel has loaded.

A feature turned red after I changed a dimension

The feature refers to an edge or face that no longer exists in the same place. Double-click the feature in the timeline, reselect the edge or face, and choose OK. Hover over the red item to see the reason.

A fillet or shell fails

The size is usually too large for the geometry, for example a fillet radius bigger than the face next to it, or a shell wall as thick as a nearby rounded edge. Try a smaller value, or apply fillets after shelling.

Exported STL looks faceted

STL is a triangle mesh. Use STEP or 3MF where the receiving software supports them: STEP keeps the exact geometry, and 3MF keeps colours and units.

macOS won't open the launcher

Right-click Start Ruffle3D (macOS).command and choose Open. The script isn't notarised by Apple, so macOS asks for confirmation the first time. Or install Ruffle3D from Chrome or Edge instead.

The model is slow to rebuild

Modelled threads, large patterns and many fillets add a lot of geometry. Move them towards the end of the timeline, or roll the marker back while you work on earlier features.

Reporting a bug

Open an issue on GitHub with:

  1. The Ruffle3D version (shown in Preferences → About) and your operating system and browser.
  2. The steps to reproduce the problem, starting from a new design if possible.
  3. What you expected to happen, and what happened instead. Include any message from the status bar or the feature's inspector.
  4. The project file (Download project file), if you are happy to share it. We only use it to fix the problem and delete it afterwards.

Response times

Ruffle3D is free, and email support is best effort: we usually reply within a few business days, and bugs that lose work come first.
