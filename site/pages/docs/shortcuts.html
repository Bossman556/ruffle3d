Keyboard shortcuts

On macOS, use ⌘ wherever this page says Ctrl. In the app, press ? to see this list.

General

Ctrl KSearch commands, actions and features
Ctrl Z / Ctrl YUndo / redo
Ctrl SSave now
Ctrl NNew design
EscCancel the current command or clear the selection
EnterConfirm the current command
TabHide or show the side panels
F6Zoom to fit
DelRemove the selected bodies
