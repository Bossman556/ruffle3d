# Code of conduct

Ruffle3D is built by people with different backgrounds, experience and skills. We want taking part to be a good experience for everyone.

## What we expect

- Be respectful and considerate, in code review as much as anywhere else.
- Assume good intent, and ask before assuming someone meant harm.
- Give feedback about the work, not the person, and accept feedback the same way.
- Help newcomers. Everyone was new once.
- Keep discussions on topic and constructive.

## What is not acceptable

- Harassment, insults, or personal or political attacks.
- Discriminatory language or behaviour of any kind.
- Sexual language or imagery.
- Publishing someone's private information without their permission.
- Any other conduct that would be inappropriate in a professional setting.

## Scope

This applies in the project's repositories, issues, pull requests, discussions and any other project space, and when someone represents the project elsewhere.

## Reporting

If someone's behaviour concerns you, contact the maintainers privately through GitHub (open a [private security advisory](https://github.com/Bossman556/ruffle3d/security/advisories/new) and mention it is a conduct report). Reports are handled confidentially.

Maintainers may remove, edit or reject comments, commits, code and issues that don't follow this code, and may temporarily or permanently ban anyone whose behaviour is harmful.
